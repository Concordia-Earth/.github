# Contributing to CONCORDIA 🌍

First off, thank you for considering contributing to CONCORDIA! CONCORDIA is a non-profit, open-source global infrastructure designed for decentralized collective decision-making.

Every contribution—whether it's code, documentation, UI/UX design, cryptography research, or translation—helps build a public good for humanity.

---

## 📜 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). Please report any unacceptable behavior to `contact@concordia.earth`.

---

## 🏛️ Legal & Governance Note

CONCORDIA is governed as a public-good open-source project:

1. **Open Source & Licensing:** All code and contributions are licensed under open-source terms (CC0 / Apache 2.0 / MIT). By submitting a Pull Request, you agree that your contributions will be made available under these public domain/open infrastructure terms.
2. **Liability Disclaimer:** As outlined in our [README.md](README.md), the software is provided "AS IS", without warranty of any kind.
3. **Institutional Roadmap:** Infrastructure and project assets (including domains and repositories) are transitionally managed under a Non-Profit Association model and will eventually transfer to a neutral global Foundation.

## 🚀 How to Contribute

### 1. Join the Discussion
Before starting major development work, please join our community channels:
- **Discord:** [Join CONCORDIA Discord](https://discord.gg/3BGTaURDq)
- **GitHub Discussions:** Check open discussions in our repositories.

### 2. Reporting Bugs & Feature Requests
- Check existing [Issues](https://github.com/Concordia-Earth/.github/issues) to avoid duplicates.
- Open a new issue with a clear title, description, and steps to reproduce (if applicable).

### 3. Submitting Pull Requests (PRs)
1. Fork the repository and create your feature branch: `git checkout -b feature/amazing-feature`.
2. Commit your changes with clear, descriptive commit messages.
3. Ensure code meets project formatting and testing standards.
4. Open a Pull Request against the `main` branch and describe your changes.
